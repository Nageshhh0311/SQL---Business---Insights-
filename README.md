# SQL Business Insights

## Project Overview
This project focuses on analyzing sales data using SQL queries to generate meaningful business insights.

## Tools Used
- SQL
- MySQL

## Dataset
The project uses a sales table containing information such as:
- Order ID
- Order Date
- Month
- Product
- Category
- City
- Quantity
- Price

## Analysis Performed
- Total Revenue Analysis
- Product-wise Sales Analysis
- City-wise Sales Analysis
- Category-wise Revenue Analysis
- Monthly Sales Analysis
- Average Price Analysis
- Top and Lowest Selling Products
- Aggregate Functions
- GROUP BY and HAVING
- ORDER BY and LIMIT

## Key Learning Outcomes
- Writing SQL queries
- Using aggregate functions
- Grouping and filtering data
- Analyzing sales performance
- Generating business insights
